Starting point

Visitor or member

Browses publicly, or signs in for private tools.

  • Consent is requested before a skin photo is sent for analysis.
  • Members can choose to publish stories anonymously.
Browser · React + Vite

ILLUMINATE app

Routes, screens, session state, and client-side services.

  • Living Wall, Skin Without Shame, messages, and member dashboard.
  • AuthContext uses Supabase Auth; services read and write member records through Supabase.
  • Skin screen posts the selected image to /api/skin-analysis.
  • Supportive-message favourites stay in browser localStorage.
Local fallback

Bundled demo data

Lets the public experience run without a Supabase project.

  • demo_stories.json supplies synthetic Living Wall stories.
  • demo_community.json supplies fabricated profiles for the similarity score.
  • The same synthetic profiles can calculate the score if the Supabase RPC is unavailable.
Database · Auth · RLS

Supabase

Browser-facing auth and data, with access enforced by database policies.

  • Auth provides member sessions.
  • Postgres stores stories, category links, time-capsule letters, and optionally parsed skin results.
  • public_stories exposes published stories while omitting private author details.
  • RLS protects drafts, private records, and account ownership; demo_similarity returns synthetic counts.
  • Schema and policies are defined in the ordered SQL migrations under supabase/migrations/.
Python · FastAPI

Backend API

Validates photo uploads and proxies skin analysis.

  • Checks image type, dimensions, and upload size before forwarding.
  • Uses server-side YOUCAM_API_KEY; keys never enter the browser.
  • Returns parsed analysis output; does not persist the uploaded image.
  • Legacy community endpoints can use a server-side Supabase service-role key. The main app's stories and member features use browser-to-Supabase requests instead.
External provider

YouCam

Processes a photo and returns skin analysis.

  • Provider terms and retention policies apply to the submitted photo.
  • Illuminate does not store the photo.
